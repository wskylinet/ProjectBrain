# Project Instructions

## Git publishing

- When asked to commit and push changes in this repository, use native `git` commands, including `git push`.
- Write Git commit messages in Chinese.
- Do not require GitHub CLI (`gh`) for a normal commit-and-push request.
- Use `gh` only when the requested GitHub operation needs it, such as creating or managing pull requests, issues, or Actions runs.

## Release artifacts

- Put all release packages in the repository-root `artifacts/` directory.
